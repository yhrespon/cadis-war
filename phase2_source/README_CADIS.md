# CADIS WAR ZONE

Projet Godot basé sur le TPS Demo, transformé en accueil et prototype de **CADIS WAR ZONE - Révolte des Robots**.

- Menu CADIS offline/local et bouton Online.
- Salon `CADIS-XXXX` généré localement.
- Lore dans `story/lore.txt`.
- Assets originaux du TPS Demo conservés.
- Export Android configuré dans `export_presets.cfg`.
